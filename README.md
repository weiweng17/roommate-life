# Roommate Life

A cozy 2.5D/isometric roommate life-sim prototype built with Godot 4.7.

## Playable MVP

- Isometric room projection and depth sorting
- Autonomous roommate needs and activity selection
- Bed / computer / fridge / shower / sofa / rainy-window interactions
- Hunger, energy, hygiene, fun, mood and bond
- Save data and offline progression
- Browser preview in `web-preview/`

## Run

Open `project.godot` with Godot 4.7.x and run the project.

For the lightweight browser preview, open `web-preview/index.html`.

## Open-source base

The 2.5D projection/world-model approach adapts MIT-licensed code concepts from `lutherfourie/net-ninja-godot`. Original branding, commissioned artwork, character designs, and restricted assets from that project are not included. See `THIRD_PARTY_LICENSES.md`.
